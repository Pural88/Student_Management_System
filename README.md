# Student Management System

Welcome to the **Student Management System**, a comprehensive web application designed to streamline the administration of student data, attendance tracking, and departmental records. 

## 🚀 Project Overview

Built as a lightweight but powerful system for educational institutions, this project provides a unified dashboard to manage the core aspects of student administration. 

### Key Features
- **Student Records Management:** Securely add, update, search, and maintain detailed student profiles and enrollment data.
- **Attendance Tracking:** Keep track of daily attendance records seamlessly.
- **Department & Branch Management:** Organize students efficiently across different academic branches and departments.
- **Secure Authentication:** Built-in user authentication and role management using Flask-Login and secure password hashing.
- **Responsive Dashboard:** A clean, user-friendly interface built with modern web technologies that looks great on both desktop and mobile devices.

## 🛠️ Technology Stack
- **Backend:** Python, Flask Framework
- **Database:** MySQL, SQLAlchemy ORM
- **Frontend:** HTML5, CSS3, Bootstrap, Jinja2 Templating
- **Security:** Werkzeug (Password Hashing)
